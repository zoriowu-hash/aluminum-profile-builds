# Aluminum Profile Builds 🛠️

A learning log for building things with aluminum extrusion profiles (T-slot / 80/20-style profiles).

## What goes here

- Notes from each build: design ideas, measurements, assembly steps
- Lessons learned and mistakes worth remembering
- Materials, connectors, and tooling references
- Photos/diagrams when useful

## Structure

- `projects/` — one file per build, in the order they're started
- (Structure can evolve as we learn what's worth recording)
